# 01 — DATABASE (current state, One Local / OL-ui)

Scope: this repository only (`OL-ui`: customer app `frontend/`, restaurant app `partner/`, server code in `frontend/server/` served through Expo Router API routes `frontend/app/api/`). Nothing was modified; nothing was run against any database.

**Conventions used in every audit file**
- (no tag) = stated in a file of this repository.
- **INFERRED** = deduced from code behaviour, not written down anywhere.
- **UNKNOWN** = cannot be determined from this repository.
- **DRAFT** = a migration file that the repo's own docs say is applied nowhere (or only on a local database).
- **DOC-CLAIM** = the repo's docs/journal say so, but nothing in code or SQL proves it.
